# 📊 StudyTrack AI – AI-Based Student Study Habit Recommender

StudyTrack AI is a AI-powered web application that analyzes student study habits and predicts marks and academic performance using Machine Learning.

---

## 🚀 Features
- User Authentication (Login / Register / Forgot Password)
- Train ML Model using CSV or Excel
- Single & Bulk Predictions
- AI-based Recommendations
- Data Visualization Dashboard
- MySQL Database Integration
- Modern SaaS-style UI

---

## 🧠 Machine Learning
- Regression model to predict student marks
- Model trained using student habit data
- Marks are used ONLY during training

---



### Training Dataset columns in dataset file.
Student,StudyHours,PlayHours,SleepHours,SocialMedia,Exercise,AttentionLevel,Marks

### Bulk Prediction Dataset columns in dataset file.
Student,StudyHours,PlayHours,SleepHours,SocialMedia,Exercise,AttentionLevel



---

## 🛠️ Tech Stack
- Frontend: HTML, CSS
- Backend: Python (Flask)
- Database: MySQL
- Machine Learning: Scikit-learn
- Visualization: Matplotlib
